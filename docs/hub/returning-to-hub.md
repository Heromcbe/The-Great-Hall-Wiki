# Returning to the Hub

Each Minecraft server has a way back to the Hub, so you can hop between worlds.

| Server | How to get back |
|--------|-----------------|
| **Aethelgard** | Find the **Return to Hub** NPCs at spawn. There's one for Java and one for Bedrock. |
| **Honeydew Homes** | Find the **Return to Hub** NPC near the world centre, around X 0, Z 0. |

You can always leave any server and rejoin the Hub the normal way. See [Joining on Bedrock & Console](joining-bedrock.md) or [Joining on Java](joining-java.md).
