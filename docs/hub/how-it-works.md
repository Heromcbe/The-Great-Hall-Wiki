# How the Hub Works

You don't need to know any of this to play, but here's what's going on behind the scenes.

## The Friend Bot

Console players can't type in a server address the way PC players can. So we run a friend bot, **TheGreatHall654**, that always shows as "online." When you join it from your Friends list, you land in the Hub.

## Java and Bedrock Together

The Hub runs on Java Edition with a bridge that lets Bedrock players connect too. That's why Bedrock players' names show with a dot in front, which keeps Java and Bedrock names from clashing.

## Transfers

When you interact with a server NPC, the Hub hands your game off to that server. You aren't playing *through* the Hub. Your game connects straight to the server you picked.

## Whitelisting

The Hub itself is open to anyone. Each server behind it has its own whitelist, which you get through [Discord onboarding](../network/join-discord.md).
