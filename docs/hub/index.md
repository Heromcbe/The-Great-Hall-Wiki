# The Great Hall Hub

The Hub is the front door to every Minecraft server in The Great Hall. It's a floating island lobby where you pick which world to play. There's no building or survival here. You just arrive, choose a server, and go.

| | |
|---|---|
| **Game** | Minecraft |
| **Platform** | Java + Bedrock (console, mobile, PC) |
| **Purpose** | Lobby for all our Minecraft servers |
| **Status** | Live |

## How to Get There

!!! tip "Step 1 for everyone: join the Discord"
    Our Minecraft servers are whitelisted. Join the Discord and complete onboarding first, or you'll be turned away when you try to travel.

    [Join the Discord](https://discord.gg/PNdRF6eg5j){ .md-button .md-button--primary }

| You play on... | How to join the Hub |
|----------------|---------------------|
| Xbox, PlayStation, Switch | [Add our friend bot](joining-bedrock.md) and join from your Friends list |
| Mobile or Windows (Bedrock) | [Add our friend bot](joining-bedrock.md), or use the details in your onboarding ticket |
| Java Edition (PC) | [Use the details in your onboarding ticket](joining-java.md) |

## Once You're There

Walk up to a server NPC and **interact** with it to travel. See [Server Select](server-select.md) for what each NPC does.
