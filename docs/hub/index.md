# The Great Hall Hub

The Hub is the front door to every Minecraft server in The Great Hall. It's a floating island lobby where you pick which world to play.

| | |
|---|---|
| **Game** | Minecraft |
| **Platform** | Java + Bedrock (including console) |
| **Purpose** | Lobby. Choose your server here. |
| **Status** | Live |

## How to Join

1. Join the Discord and complete onboarding.
2. **Console players:** add **TheGreatHall654** as an Xbox friend, then join from the Friends tab in Minecraft.
3. **Java, PC, and mobile players:** use the details in your onboarding ticket.
4. On the island, **right-click** a server NPC to travel there.
