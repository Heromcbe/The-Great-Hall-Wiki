# Joining on Java

Java Edition players connect to the Hub by adding it as a server.

!!! warning "Onboarding first"
    You can visit the Hub without being whitelisted, but you won't be able to travel to our servers until you've finished [Discord onboarding](../network/join-discord.md).

## Add the Hub

1. Finish onboarding in the [Discord](https://discord.gg/PNdRF6eg5j). Your onboarding ticket has the Hub's address.
2. In Minecraft Java, go to **Multiplayer → Add Server**.
3. Enter a name (for example, *The Great Hall Hub*) and paste the address from your ticket.
4. Select **Done**, then join.

Use the latest release of Minecraft Java Edition.

## Traveling

Walk up to a server NPC and **right-click** it. Java players use the **Java** NPCs. See [Server Select](server-select.md).

Having trouble? See [Troubleshooting](troubleshooting.md).
