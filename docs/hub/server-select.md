# Server Select NPCs

The Hub island has an NPC for each of our servers. Walk up and **interact** with one (right-click on PC, left trigger on a controller, tap on mobile). Just walking into an NPC does nothing.

## Minecraft Servers (These Transfer You)

| NPC | Who it's for | What happens |
|-----|--------------|--------------|
| **Aethelgard** | Bedrock players | Sends you to Aethelgard |
| **Aethelgard Java** | Java players | Sends you to Aethelgard |
| **Honeydew Homes** | Bedrock players | Sends you to Honeydew Homes |

!!! info "Why two Aethelgard NPCs?"
    Aethelgard supports both Java and Bedrock, but the two editions connect differently behind the scenes. Use the one that matches the edition you're playing on.

!!! info "Honeydew is Bedrock-only"
    Java players can't join Honeydew Homes.
