# Eldervine FAQ

??? question "How do I join Eldervine?"
    Join the [Discord](https://discord.gg/PNdRF6eg5j) and complete onboarding. Your onboarding ticket has the connection details. Server addresses are never posted publicly.

??? question "Is Eldervine modded?"
    No. Eldervine runs on **Vanilla Settings**, so it plays just like standard Hytale.

??? question "I can't connect. What should I check?"
    - Make sure your Hytale game is fully updated.
    - Double-check the details against your onboarding ticket.
    - Try turning off any VPN.
    - After a Hytale update, the server may need a little time to catch up. Check the Discord for announcements.

??? question "Is PvP allowed?"
    No. Eldervine is a PvE community server. The focus is on building, exploring, and playing together.

??? question "Can I build something huge?"
    Yes! Mega builds are welcome, as long as they don't cause lag. If staff notices a build is hurting performance, they'll work with you to optimize it.

??? question "A teleporter dropped me inside someone's base. Am I in trouble?"
    Not if you leave right away and let the owner know. Accidents happen. Sticking around, snooping, or taking anything is what turns an accident into a rule break.

??? question "I set up a teleporter to my base. Anything I need to do?"
    Yes. Clearly label it as private so other players know where it goes.

??? question "Can I change or improve someone else's base?"
    Only if they invite you to. Everyone's build is their own, even on a community server.

??? question "The server seems to be down. What's going on?"
    Check the Eldervine channel in the [Discord](https://discord.gg/PNdRF6eg5j) for announcements. If there's nothing posted, let staff know.

??? question "Where are the full rules?"
    See the Rules section on the [Eldervine page](index.md#rules) for a summary. The [full rulebook (PDF)](https://github.com/Heromcbe/The-Great-Hall-Docs/blob/main/The_Great_Hall_Rules.pdf) is the official version.
