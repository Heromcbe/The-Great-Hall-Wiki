# World Map

Honeydew has a **live web map** of the whole world, so you can scout for biomes, structures, and a spot to build without leaving home.

[Open the Honeydew map](https://heromcbe.github.io/Honeydew-Homes-SMP){ .md-button .md-button--primary }

## What's on It

- **All three dimensions:** the Overworld, the Nether, and the End
- The whole world, about 17,000 × 17,000 blocks
- Zoom in to see individual builds, or out to see whole regions

## How Often It Updates

The map updates **once a day**, after the daily server restart early in the morning (Eastern time). Anything built today shows up on tomorrow's map.
