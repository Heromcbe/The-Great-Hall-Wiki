# Returning to the Hub

Want to hop over to another Minecraft server? Head back to **The Great Hall Hub**.

## How to Get Back

Find the **Return to Hub NPC** near the world centre, around **X 0, Z 0**. Interact with it and you're sent back to the Hub.

From the Hub you can pick any Minecraft server. See [Server Select NPCs](../hub/server-select.md).

!!! tip "Or just rejoin"
    You can also leave Honeydew and rejoin the Hub the normal way. See [Joining on Bedrock & Console](../hub/joining-bedrock.md).
