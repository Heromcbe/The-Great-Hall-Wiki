# Corstinite

Corstinite is Better on Bedrock's mid-to-high tier metal. HeroBoB+ adds a full set of Corstinite tools to go with Better on Bedrock's Corstinite armor.

## Tools

| Tool | Damage | Durability |
|---|---|---|
| Sword | 8 | 550 |
| Pickaxe | 6 | 600 |
| Axe | 8 | 550 |
| Shovel | 5 | 500 |
| Hoe | 3 | 400 |

- **Mines everything**, including obsidian and ancient debris.
- **Doesn't burn** in lava or fire.
- **Repair** with a Corstinite Ingot at an anvil.

## Crafting

Craft at a normal crafting table, in the same shape as the diamond version of each tool, using **Corstinite Ingots** and **Sticks**.

| Tool | Corstinite Ingots | Sticks |
|---|---|---|
| Sword | 2 | 1 |
| Pickaxe | 3 | 2 |
| Axe | 3 | 2 |
| Shovel | 1 | 2 |
| Hoe | 2 | 2 |

## Armor

Corstinite armor comes from Better on Bedrock. On Honeydew, wearing the **full set** gives you **Fire Resistance**. See [Armor & Set Bonuses](../armor-and-set-bonuses.md).
