# Bug Fixes

HeroBoB+ fixes a lot of what was broken in Better on Bedrock. Here are the fixes you'll notice in-game.

## Player & Combat

- **Player animations restored:** eating, swimming, sneaking, and attack swings work normally again.
- **Amethyst armor:** the full-set knockback bonus now works.
- **Custom tools lose durability properly:** Better on Bedrock and HeroBoB+ tools now wear down like vanilla tools, and Unbreaking works on them.

## Spears

- **All 10 spears can be thrown** and return with Loyalty.
- **All spears can be repaired** at an anvil. Before, none could.
- Removed the debug messages spears used to spam in chat.

## Trees & Blocks

- **Custom tree canopies decay** after you chop the trunk. See [Leaf Decay](trees-and-saplings/leaf-decay.md).
- **Orange leaves** drop the right items when they decay.
- **Tree Capitator and Leafy Liberator** work on more trees, including poplar and pale oak.

## Crafting

- **Forge Table:** now checks you have the right number of ingots before it takes anything.

## Performance

Many of Better on Bedrock's background scripts were rewritten to cut server lag.
