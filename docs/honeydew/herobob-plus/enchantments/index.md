# Enchantments

Better on Bedrock adds special enchantments that you apply at the **Miner's Bench**, not an enchanting table. HeroBoB+ adds three new ones and lets more tools use them.

## Using the Miner's Bench

1. Hold the tool you want to enchant.
2. Have the matching **enchantment book** in your inventory.
3. Interact with the Miner's Bench and pick the enchantment.

Each enchantment costs **6 levels** and uses up the book. The menu only shows enchantments that fit your tool and that it can still take.

## Enchantments by Tool

| Tool | Enchantment | What it does |
|---|---|---|
| Pickaxe | Vein Miner I | Mines a whole ore vein at once |
| Pickaxe | Auto Smelter I | Smelts ores as you mine them |
| Pickaxe | [**Boring I**](boring.md) (new) | Bores a 9-block tunnel or a 3×3×3 cube |
| Axe | [Tree Capitator I](tree-capitator.md) | Fells the whole trunk |
| Axe | [Leafy Liberator I](leafy-liberator.md) | Clears the whole canopy |
| Hoe | Harvest Touch I | Better on Bedrock's crop harvesting enchantment |
| Hoe | [Leafy Liberator I](leafy-liberator.md) | Clears the whole canopy |
| Hoe | [**Auto Replant I**](auto-replant.md) (new) | Replants crops as you harvest |
| Shovel | [**Vein Excavator I**](vein-excavator.md) (new) | Digs out connected gravel and clay |
| Shears | [Leafy Liberator I](leafy-liberator.md) | Clears the whole canopy |

## Pick One

Some enchantments can't go on the same tool:

- **Pickaxe:** Boring, Vein Miner, and Auto Smelter. Choose one.
- **Hoe:** Auto Replant or Harvest Touch. Choose one. Auto Replant also can't go on a hoe with Silk Touch.

## Where to Get Books

| Seller | Books | Price |
|---|---|---|
| **Goblin Trader** | Vein Miner, Tree Capitator, Leafy Liberator, Harvest Touch, Auto Smelter, plus one of Auto Replant, Vein Excavator, or Boring | 6 Gold Ingots each |
| **Librarian villagers** | Auto Smelter, Vein Miner, Tree Capitator, Leafy Liberator, Harvest Touch, Auto Replant, Vein Excavator | Varies |

The Goblin Trader offers a random selection each visit, so check back if the book you want isn't there.

!!! tip "Sneak to switch it off"
    Tree Capitator, Leafy Liberator, Vein Miner, Vein Excavator, and Auto Replant don't trigger while you're sneaking. Boring is different: sneaking changes its shape.
