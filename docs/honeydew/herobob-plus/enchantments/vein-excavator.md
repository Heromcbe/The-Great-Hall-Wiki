# Vein Excavator

**Vein Excavator I** is a shovel enchantment: dig one block of gravel or clay and the whole connected patch comes with it.

| | |
|---|---|
| **Tool** | Shovel |
| **Applied at** | Miner's Bench (6 levels + Vein Excavator book) |
| **Works on** | Gravel and clay |
| **Turn it off** | Sneak while digging |

## How It Works

- Dig gravel or clay and every connected block of the same type breaks too, up to **128 blocks**.
- Everything drops where you dug the first block.
- Your shovel loses **1 durability per extra block**.
- Works alongside any other shovel enchantment.

## Drops

| Block | Normal | With Silk Touch |
|---|---|---|
| **Gravel** | Gravel, with a chance of Flint per block | Gravel blocks |
| **Clay** | 4 Clay Balls per block | Clay blocks |

**Fortune** raises the Flint chance: 10% normally, 14% with Fortune I, 25% with Fortune II, and **every block drops Flint** with Fortune III.

## Getting the Book

Buy it from the **Goblin Trader** (6 Gold Ingots, when it's in stock) or a **Librarian** villager.
