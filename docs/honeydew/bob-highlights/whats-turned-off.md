# What's Different on Honeydew

Honeydew runs a tuned version of Better on Bedrock. A few things work differently from a normal Better on Bedrock world.

## Structures

Better on Bedrock structures **no longer generate** in new land. The ones already in the world are still there to explore. See [Structures](structures.md).

## Performance

Some of Better on Bedrock's background scripts have been switched off or rewritten to keep the server running smoothly. Most players won't notice any difference, except less lag.

## Improved by HeroBoB+

Many Better on Bedrock systems have been replaced with fixed versions: spears, tree and leaf enchantments, leaf decay, the Forge Table, and more. See [Bug Fixes](../herobob-plus/bug-fixes.md).
