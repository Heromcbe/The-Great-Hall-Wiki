# Backpacks

Backpacks give you extra storage you can carry anywhere. Honeydew uses Better on Bedrock's standard backpacks.

## Sizes

| Backpack | Slots | Special ingredient |
|---|---|---|
| Backpack | 18 | 2 Copper Ingots |
| Medium Backpack | 36 | 2 Diamonds |
| Large Backpack | 54 | 2 Netherite Ingots |

## Crafting

All three use the same layout at a crafting table:

| | | |
|:-:|:-:|:-:|
| Deer Hide | Stronger String | **Special** |
| Stronger String | Chest | Stronger String |
| **Special** | Stronger String | Deer Hide |

**Special** is the ingredient from the table above.

**Stronger String:** 5 String + 4 Deer Hide in a checkerboard makes 4 Stronger String. **Deer Hide** drops from deer.

## Using a Backpack

1. **Hold the backpack in your main hand.** It appears in front of you.
2. **Interact with it** to open it.
3. Switch to another item and your backpack saves and closes.

Each backpack keeps its own contents, even if you have more than one.

## Rules

- You **can't put backpacks or shulker boxes** inside a backpack.
- Backpacks **won't open next to a portal or waystone**. Step away and try again.
