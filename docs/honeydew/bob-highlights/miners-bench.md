# Miner's Bench

The **Miner's Bench** is Better on Bedrock's enchanting station for special tool enchantments, like Tree Capitator, Vein Miner, and our own [HeroBoB+ enchantments](../herobob-plus/enchantments/index.md).

## Crafting

| | | |
|:-:|:-:|:-:|
| Tin Ingot | Book | Tin Ingot |
| Planks | Planks | Planks |

Any type of planks works.

## Using It

1. Hold the tool you want to enchant.
2. Have the **enchantment book** in your inventory.
3. Interact with the Miner's Bench and choose the enchantment.

| | |
|---|---|
| **Cost** | **6 levels** per enchantment, plus the book |
| **Works on** | Pickaxes, axes, hoes, shovels, and shears |

The full list of enchantments, what they do, and where to buy the books is on the [Enchantments](../herobob-plus/enchantments/index.md) page.
