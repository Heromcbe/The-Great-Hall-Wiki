# Cybers Structures QoL+

An upgraded take on the classic Structures Plus (S+) system. Better building pieces, plus terminals that automate a lot of the grind.

## Building

- Improved snapping for cleaner placement
- A huge set of structures: over 200 in total
- Storage, fridges with longer spoil times, vaults, and a cryofridge

## Automation Terminals

| Terminal | What it does |
|----------|--------------|
| **Nanny** | Feeds and imprints babies |
| **Hatchery** | Incubates eggs |
| **Farmer** | Collects fertilizer |
| **Gardener** | Harvests crops |
| **Item Aggregator** | Gathers items from nearby |
| **Auto Crafter** | Crafts for you |
| **Healing / Charge / Repair stations** | Heal creatures, charge batteries, repair gear |

Many crafting stations also have upgraded versions with more slots and faster crafting.

## Handy Tools

- **Pull system:** crafting stations can pull resources from nearby containers and creatures, so you don't have to move everything by hand.
- **Multi Tool:** demolish your structures, manage creatures, repair items, and more.
- **Omni Tool:** move items between inventories and scan creatures.
- **Stat reset** for tamed creatures if you put points in the wrong place.

## Remember the Rules

Automated setups are great, but keep them reasonable. The [Wyrmwood rules](../index.md#rules) ask you to keep your tame count and builds from lagging the server.
