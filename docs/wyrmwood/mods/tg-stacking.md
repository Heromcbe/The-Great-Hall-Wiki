# TG Stacking Mod 10000-90

Hauling resources in ARK gets heavy fast. This mod fixes that.

## What It Does

- **Resources stack to 10,000** instead of the usual small stacks.
- **Items weigh 90% less**, so you can carry far more before you're overweight.
- **Ammo and kibble** stack higher too, but they have their own smaller limit.

## Good to Know

- Crafted resources like **Sparkpowder** and **Cementing Paste** use the mod's versions. If yours don't stack, you may need to re-learn those engrams.
- Items made before you joined may not stack with new ones. Newly crafted items stack normally.
