# Creatures

Wyrmwood runs **Ragnarok Bonus Spawns**, which adds creatures to Ragnarok that don't normally live there.

## Bonus Spawns

| Creature | Where to find it |
|----------|------------------|
| **Phoenix** | The Dunes |
| **Reaper** | The Dunes |
| **Rock Drake** | The Wyvern Cave |
| **Shastasaurus** | The ocean |
| **Snow Owl** | The Snowy Forest |

## Good to Know

- **Rock Drakes drop Red Gems** when killed. You need those to craft a Rock Drake saddle.
- Saddle engrams for the **Snow Owl** and **Rock Drake** are added.
- Be ready before you head into the Dunes or the Wyvern Cave. These are dangerous places.

## Remember the Rules

- Don't wall off spawn areas, caves, or obelisks.
- Clean up taming traps when you're done.
- Keep your tame count reasonable. See the [Wyrmwood rules](index.md#rules).
