# Wyrmwood

Wyrmwood is our ARK: Survival Ascended server on the Ragnarok map. It's a small PvE server with quality-of-life mods.

| | |
|---|---|
| **Game** | ARK: Survival Ascended |
| **Map** | Ragnarok |
| **Mode** | PvE |
| **Player cap** | 8 |
| **Mods** | Quality-of-life mods, downloaded automatically when you join |
| **Status** | Live |

## How to Join

1. Join the Discord and complete onboarding.
2. Your onboarding ticket has the server details and password.

[Join the Discord](https://discord.gg/PNdRF6eg5j){ .md-button .md-button--primary }
