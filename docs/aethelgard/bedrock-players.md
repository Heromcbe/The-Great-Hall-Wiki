# Bedrock Players

Aethelgard is a Java server that Bedrock players can join too: console, mobile, and Windows. Everyone plays in the same world.

## Joining

Bedrock players join through **The Great Hall Hub**. Use the **Aethelgard (Bedrock)** NPC at the Hub. See [Joining on Bedrock & Console](../hub/joining-bedrock.md).

## Your Name Has a Dot

Bedrock players' names start with a **dot** on Aethelgard, like **.PlayerName**. That's how the server tells Bedrock and Java players apart.

!!! tip "Typing a Bedrock player's name"
    When a command needs a Bedrock player's name (like adding them to your claim), include the dot: `/aclaim add * .PlayerName`.

## Skins

Your Bedrock skin shows up for everyone, including Java players.

## Everything Works the Same

Bedrock players can use everything Java players can:

- **Land claims:** see [Land Claims](land-claims.md)
- **Shops and coins:** see [Shops](shops/index.md) and [Aethelgard Coins](economy/coins.md)
- **Graves:** see [Graves](graves.md)

Menus may look a little different on Bedrock, but they work the same way.

## Getting Back to the Hub

Use the **Return to Hub (Bedrock)** NPC at spawn. See [Returning to the Hub](returning-to-hub.md).
