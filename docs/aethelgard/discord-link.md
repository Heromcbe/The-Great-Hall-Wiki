# Discord Link

Aethelgard is connected to The Great Hall Discord through **HeroBridge**, our own Discord bot.

## What It Does

| Feature | What it means for you |
|---|---|
| **Two-way chat** | Messages sent in Aethelgard show up in Discord, and Discord messages show up in-game. |
| **Player tracking** | See who's online and when players join or leave. |
| **Time played** | HeroBridge keeps track of how long you've played. |
| **Server access** | Your access to Aethelgard is set up through Discord onboarding. |
| **Moderation** | Staff use HeroBridge to keep the server safe and fair. |

!!! note "Chat rules apply everywhere"
    Because chat is shared between the game and Discord, the [Community Rules](../network/community-rules.md) apply to what you say in both places.
